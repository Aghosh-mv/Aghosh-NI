# NI - Natural Intelligence Project

## Mission
Study the actual human brain. Understand how it computes. Build computational models based on real neuroscience, not LLM pattern matching.

## Core Insight
LLMs predict the next token. Brains do something fundamentally different:
- They maintain a **world model** they can simulate
- They use **causal reasoning** (not correlation)
- They have **embodied grounding** (sensors + actuators)
- They learn through **experience**, not training data
- They are **energy efficient** (20 watts vs megawatts)

## Project Structure

```
natural-intelligence/
├── brain_atlas/          # Mapping brain structures to computation
├── neural_mechanisms/    # How neurons actually compute
├── cognitive_systems/    # High-level brain systems
├── implementations/      # Computational models
├── experiments/          # Testing against brain data
└── research/             # Papers, references, findings
```

## Approach
1. **Understand** - Study what the brain actually does (not what we assume)
2. **Map** - Find computational equivalents for biological mechanisms
3. **Implement** - Build those mechanisms in code
4. **Validate** - Test against actual brain data
5. **Extend** - Use insights to build NEW capabilities
